# N-Back Memory Game

An interactive N-back memory training game built with React.  
The app supports multiple N-levels (1-back, 2-back, 3-back, …) and visual/auditory stimuli depending on the implementation.

## Features

- Classic **N-back** cognitive task
- Support for **N = 1–X** (choose difficulty)
- Visual and/or auditory stimuli
- Score tracking
- Responsive UI
- Configurable game speed
- Highlighting of matches/mismatches
- Clean component-based React architecture

## Tech Stack

- **React** (JavaScript/TypeScript)
- **CSS** / your styling of choice
- **Vite** or **Create React App** (depending on your setup)
